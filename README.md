# Plain Life 4000 Simulation

用于模拟 4000 个人类单位在平原环境中生活的独立项目。

当前状态：空白项目模板。尚未选择语言、引擎、框架、数据格式或运行方式。

## 项目目标

- 建立包含 4000 个人类单位的平原生活模拟。
- 模拟范围和技术路线由后续需求决定。
- 在技术选型前不预设实现方式。

## 当前内容

- 独立 Git 仓库和提交规则。
- 项目目标简报。
- 技术决策记录模板。
- 通用忽略规则。
