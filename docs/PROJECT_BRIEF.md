# 项目简报

## 目标

模拟 4000 个人类单位在平原环境中生活。

## 当前状态

Phase 1 已建立版本化核验：

- 世界固定为 50 平方公里，环境必须先于人物生成。
- 封闭边界、天气输入输出、生存依赖、季节窗口和人口一致性已有结构化门禁。
- v1 温带秋季基线和失败结果已冻结。
- v2 暖湿早季诊断版已冻结。
- v3 保留固定人口年度压力测试和第一版七天诊断。
- v4 已接入家庭分配、局部求助、火种、照护、住所和基础教学。
- v4 已完成同初始条件的七天动态/固定能力对照。
- v5 已核对替代资源的季节拒绝，并追踪捕鱼退出家庭、替代资源和劳动时间去向。
- v5 已提交初步开局相容性评估；空间可接触性仍是生态结论前的混杂因素。
- v6 已证明有限候选与发现规则造成假性受困，并在完整位置信息诊断下仍保留
  实际获取不足。
- R1/S01-0 现状清点和 S01-1 契约执行核心已新增；旧诊断基线继续冻结。
- S01-1 核心契约已验收；第一条移动取水链已接入统一 core。
- 已实现基础饮水、食物、遮蔽、火、工具、探索和迁移核验。
- v6 七天动态诊断仍暴露严重食物缺口；正式长期模拟仍处于阻断状态。

尚未确定：

- 实际地形、生态、资源和人口快照。
- 模拟的真实度、抽象层级和时间尺度。
- 单位是独立智能体、统计个体还是混合模型。
- 长期运行引擎、空间划分和性能目标。
- 可视化、交互方式和结果观察方式。

## 待补充

1. 隔离营地集中、共享候选资源格和实际可接触供给对食物缺口的影响。
2. 实现有依据的个人资源发现、记忆、交流和迁移后候选更新，再做三组对照。
3. 明确并校准恢复、失能、疾病和死亡参数。
4. 扩展承诺、信任变化、教学网络和跨家庭长期协作。
5. 重新核验人物时间、资源和生存路径。
6. 明确长期模拟的时间尺度、观察尺度、平台和性能目标。

## 约束

- Phase 1 生成、核验、审计和报告使用 Python 3.12 标准库。
- 专项试运行不写入正式世界历史，也不代表已实现可信的人类社会模拟。
- Git 管理和共享缓存规范适用。
