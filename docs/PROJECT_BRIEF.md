# 项目简报

## 目标

模拟 4000 个人类单位在平原环境中生活。

## 当前状态

Phase 1 已建立版本化核验：

- 世界固定为 50 平方公里，环境必须先于人物生成。
- 封闭边界、天气输入输出、生存依赖、季节窗口和人口一致性已有结构化门禁。
- v1 温带秋季基线和失败结果已冻结。
- v2 暖湿早季诊断版已冻结。
- v3 已修正报表口径、季节损失和水火路径，并实现个人与家庭基础短场景。
- 已实现基础饮水、食物、遮蔽、火、工具、探索和迁移核验。
- v3 四个时间窗全部失败；正式长期模拟仍处于阻断状态。

尚未确定：

- 实际地形、生态、资源和人口快照。
- 模拟的真实度、抽象层级和时间尺度。
- 单位是独立智能体、统计个体还是混合模型。
- 长期运行引擎、空间划分和性能目标。
- 可视化、交互方式和结果观察方式。

## 待补充

1. 将已通过短场景的家庭分配和请求回应并入年度人口。
2. 将连续身体后果并入年度人口，并定义有依据的恢复和失能过程。
3. 明确伤害、疾病、死亡及其对劳动能力的影响。
4. 扩展信任变化、承诺、教学网络和跨家庭协作。
5. 重新核验人物时间、资源和生存路径。
6. 明确长期模拟的时间尺度、观察尺度、平台和性能目标。

## 约束

- Phase 1 生成、核验、审计和报告使用 Python 3.12 标准库。
- 专项试运行不写入正式世界历史，也不代表已实现可信的人类社会模拟。
- Git 管理和共享缓存规范适用。
