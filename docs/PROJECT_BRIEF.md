# 项目简报

## 目标

模拟 4000 个人类单位在平原环境中生活。

## 当前状态

Phase 1 已建立版本化核验：

- 世界固定为 50 平方公里，环境必须先于人物生成。
- 封闭边界、天气输入输出、生存依赖、季节窗口和人口一致性已有结构化门禁。
- v1 温带秋季基线和失败结果已冻结。
- v2 暖湿早季诊断版已冻结。
- v3 保留固定人口年度压力测试和第一版七天诊断。
- v4 已接入家庭分配、局部求助、火种、照护、住所和基础教学。
- v4 已完成同初始条件的七天动态/固定能力对照。
- 已实现基础饮水、食物、遮蔽、火、工具、探索和迁移核验。
- v4 七天动态诊断仍暴露严重食物缺口；正式长期模拟仍处于阻断状态。

尚未确定：

- 实际地形、生态、资源和人口快照。
- 模拟的真实度、抽象层级和时间尺度。
- 单位是独立智能体、统计个体还是混合模型。
- 长期运行引擎、空间划分和性能目标。
- 可视化、交互方式和结果观察方式。

## 待补充

1. 分析 v4 食物链中局部资源耗尽、知识不足和加工受阻的主次关系。
2. 明确并校准恢复、失能、疾病和死亡参数。
3. 扩展承诺、信任变化、教学网络和跨家庭长期协作。
4. 重新核验人物时间、资源和生存路径。
5. 明确长期模拟的时间尺度、观察尺度、平台和性能目标。

## 约束

- Phase 1 生成、核验、审计和报告使用 Python 3.12 标准库。
- 专项试运行不写入正式世界历史，也不代表已实现可信的人类社会模拟。
- Git 管理和共享缓存规范适用。
