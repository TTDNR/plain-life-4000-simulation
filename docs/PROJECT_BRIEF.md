# 项目简报

## 目标

模拟 4000 个人类单位在平原环境中生活。

## 当前状态

Phase 1 已建立版本化核验：

- 世界固定为 50 平方公里，环境必须先于人物生成。
- 封闭边界、天气输入输出、生存依赖、季节窗口和人口一致性已有结构化门禁。
- v1 温带秋季基线和失败结果已冻结。
- v2 暖湿早季修正版已生成资源、人口和专项压力测试结果。
- 已实现基础饮水、食物、遮蔽、火、工具、探索和迁移核验。
- v2 四个时间窗全部失败；长期模拟处于阻断状态。

尚未确定：

- 实际地形、生态、资源和人口快照。
- 模拟的真实度、抽象层级和时间尺度。
- 单位是独立智能体、统计个体还是混合模型。
- 长期运行引擎、空间划分和性能目标。
- 可视化、交互方式和结果观察方式。

## 待补充

1. 定义家庭成员之间有差异、可拒绝和会冲突的食物分配。
2. 定义家庭之间的食物、火种、照护和知识交换或拒绝规则。
3. 定义信任形成、信息传播和有限信息迁移决策。
4. 明确伤害、疾病、死亡及其对劳动能力的影响。
5. 补齐自然损失、储存、加工和食品保存模型后重新核验。
6. 明确长期模拟的时间尺度、观察尺度、平台和性能目标。

## 约束

- Phase 1 生成、核验、审计和报告使用 Python 3.12 标准库。
- 专项试运行不写入正式世界历史，也不代表已实现可信的人类社会模拟。
- Git 管理和共享缓存规范适用。
