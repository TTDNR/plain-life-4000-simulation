# 项目简报

## 目标

模拟 4000 个人类单位在平原环境中生活。

## 当前状态

空白项目。尚未确定：

- 模拟的真实度、抽象层级和时间尺度。
- 单位是独立智能体、统计个体还是混合模型。
- 世界范围和空间划分。
- 资源、社会关系、行为和生存规则。
- 技术栈、运行平台和性能目标。
- 可视化、交互方式和结果观察方式。

## 待补充

1. 场景和时间范围。
2. 人类单位需要模拟的状态。
3. 平原环境包含哪些资源和限制。
4. 希望观察的宏观或微观现象。
5. 单机运行、服务化运行或分布式运行的预期。
6. 目标帧率、模拟速度或批量计算吞吐量。
