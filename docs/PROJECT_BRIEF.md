# 项目简报

## 目标

模拟 4000 个人类单位在平原环境中生活。

## 当前状态

Phase 1 已完成工程骨架：

- 世界固定为 50 平方公里，环境必须先于人物生成。
- 封闭边界、天气输入输出、生存依赖、季节窗口和人口一致性已有结构化门禁。
- 当前没有足够的具体生态和人口数据，因此长期模拟处于阻断状态。

尚未确定：

- 实际地形、生态、资源和人口快照。
- 模拟的真实度、抽象层级和时间尺度。
- 单位是独立智能体、统计个体还是混合模型。
- 长期运行引擎、空间划分和性能目标。
- 可视化、交互方式和结果观察方式。

## 待补充

1. 补齐 Phase 1 环境实体及来源。
2. 生成一致的 4000 人家庭与经历快照。
3. 完成四个时间窗的生存路径计算。
4. 明确长期模拟的时间尺度和观察尺度。
5. 明确运行平台和性能目标。
6. 明确可视化、交互方式和结果观察方式。

## 约束

- Phase 1 审计工具使用 Python 3.12 标准库，不构成长期模拟引擎选型。
- Git 管理和共享缓存规范适用。
