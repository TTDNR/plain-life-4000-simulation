但还可能是候选格排序和共同营地选择的模型简化，不能直接等同于真实生态承载力。

## 资源账与结论边界

- 鱼类期初 120,163.42092 kg，期末 99,785.228237 kg，采集 20,828.640495 kg。
- 鱼类并未在 50 km² 全图耗尽。
- 238 个退出家庭中 235 个是“其已知候选资源格耗尽”，不是“全图无鱼”。
- 当前结论只能说明现有行为与空间获取规则下局部供给快速下降。
- 不能据此宣称全局生态供给必然不足，也不能据此宣称长期自然再生可支持生存。

## 审计分类

| 问题 | 分类 | 处理 |
| --- | --- | --- |
| 路径记录缺少世界年内日期 | 模型或报告错误 | 已修复并回归检查 |
| 季节审计混入其他拒绝原因 | 模型或报告错误 | 已拆分资源级原因 |
| 捕鱼退出归因过度依赖泛化计数 | 模型或报告错误 | 已改为退出队列和鱼资源级证据 |
| 全局鱼类不足 | 未获证据的结论 | 撤销；仅保留局部候选格耗尽 |
| 空间集中导致退出 | 可信模型产生的结果 | 保留，并进入相容性评估 |
| 正替代资源仍不能覆盖需求 | 可信模型产生的结果 | 保留，不调参救场 |
| 长期生存路径 | 尚未证明 | 不通过 |
