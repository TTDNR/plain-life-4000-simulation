# v5 变更记录

## 范围

v5 保留 v1–v4 的失败结果，只补充本轮要求的两个诊断问题：

1. 替代资源的季节拒绝是否正确。
2. 第 2 日参与捕鱼、第 4–5 日退出的家庭为何退出，劳动时间去了哪里。

没有通过增加资源、改变初始技能、提高合作意愿或减轻身体后果来追求通过。

## 证据修正

- 食物路径记录补全世界年内日期。此前缺少该字段只影响汇总证据，
  不影响季节判断函数本身。
- 拒绝记录改为按资源、资源和资源格保存样本，不再只保留全局前 40 条。
- 新增候选格统计：扫描数、正存量格、正存量 kg、被选格、被选原料和被选可食产出。
- 新增逐资源实际活动统计：采集时间、加工时间、往返时间和加工失败。
- 季节审计只从 `outside_availability_window` 记录生成样本，不再把其他拒绝原因
  混入季节证据。
- 捕鱼退出改为家庭队列：分别报告全体参与、来自第 2 日队列的继续参与、
  退出队列类别、替代资源、时间去向和空间集中。

本版本复用相同世界、人口、行动和身体规则，运行标识仍为
`10cad56caa6fd382`。主要失败指标与修正前 v5 一致：

| 指标 | 修正前 v5 | 当前 v5 |
| --- | ---: | ---: |

| 第 4 日食物摄入/需求 | 0.3123 | 0.3123 |

因此本轮变化属于证据补齐，不是通过调参改善生存结果。

## 当前结论

- 鹿、兔、鱼、水禽、香蒲和春季嫩叶没有季节拒绝记录。
- 真实被季节拒绝的是箭叶、浆果、榛子和橡子。
- 鱼类退出主因是已知候选格局部耗尽，不是短期全局鱼类不足。
- 捕鱼减少后，退出队列的食物获取类别由第 2 日 18.3183 家庭小时降至
  第 4–5 日均值 11.8681；未分配或休息能力由 0.4650 增至 5.5074。
- 退出家庭仍在第 4–5 日选择水禽、兔和鹿，但平均可食产出远低于退出前的鱼。
