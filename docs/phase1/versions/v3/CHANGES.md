# v3 变更记录

## 范围

v3 按需求组给出的顺序实施第一项修正、第一批个人行为和第二批基础家庭行为。
复杂信任变化、承诺、教学网络、跨家庭长期协作、统一市场和政治制度仍不在本轮范围。

## 报表与生态修正

- 初期食物路径改为只统计投放后第 1–3 日，全试运行累计单独列出。
- 时间窗写明投放后日数、世界年内日序、是否跨年和互不重叠范围。
- “有家庭不足 80% 的天数”和“累计不足 80% 家庭日”分开记录。
- 最低满足率明确为最困难家庭日。
- 植物过季后发生自然损失；动物逻辑增长明确为包含自然死亡影响的净增长。
- 水具改为木、纤维和黏土制作的实际容器，记录制作者、尝试、失败、材料、工具和漏损。
- 取火区分首次尝试、实际点火尝试、时间不足、材料不足和点火失败。
- 遮蔽报告覆盖人数，不要求每户独立建房。
- 增加互斥个人时间账，同一时间不能重复计入。
- 未知道路的行动改为“探索未知方向”，不再伪装成已知远方资源点。
- 照护请求记录可用时间、意愿、答复和实际接手。
- 食物转移按具体食品、公斤、状态和容器记录，热量只用于核算。
- 加工学习按操作成功或失败推进，不采用固定三次门槛。
- 共享火和提供临时住所拆成两个决定，各自记录容量与同意。
- `低于 80% 需求` 成为明确标记；分配与进食拆开记录。

## 第一批行为

- 建立连续身体状态、疲劳、睡眠债、疼痛、伤病、移动能力和劳动能力。
- 建立任务时间区间和位置，拒绝重叠任务。
- 建立个人知识阶段：听说、路线、演示、指导练习、独立、可教学。
- 短场景验证照护冲突、持续饥饿、个人发现、教学和事件回看。
- 增加拒绝照护、无余粮拒绝、练习失败、住满和只分配未进食等反向对照。

## 第二批基础行为

- 家庭内食物主张和实际分配可以不同，允许反对和主动少取。
- 邻居请求支持赠与、交换、借贷、拒绝等路径。
- 火与临时住所共享考虑距离、携带时间、事项信任和求助者风险。
- 照护责任会改变任务安排和劳动时间。

## 当前结果

- 门禁：`BLOCKED`。
- 资源账：14 类资源闭合、非负。
- 时间账：闭合误差约 `-0.000016` 小时。
- 固定人口需求压力测试：四个时间窗全部失败。
- 无成本重分配后仍有 340 天不足，不能把失败主要归因于缺少合作。
- 人物与家庭短场景：8 个全部通过。
- 七天整合诊断：4000 人连续运行；所有七天食物不足，六天饮水不足。
- 七天整合中跨家庭交换、教学和同居均未被强制触发，记录为零。

## 原因诊断补充

- 七天报告加入逐家庭缺水追踪，记录水源距离、可行动人数、依赖人数、
  取水方式、可用工时、紧急取水、照护重叠和失败原因。
- 社会行为按需求、接触、考虑、请求、回应、执行六阶段审计；未接入阶段明确标为
  `not_connected`，不再把零事件解释为人物不愿意合作。
- 个人活动记录按人物、任务类别、起止时间、资格和使用能力汇总，检查重叠与超限。
- 增加固定初始劳动能力对照，用于隔离身体反馈影响。
- 遮蔽报告增加尝试工时、部分保护人数和进度保留状态。

## 七天改动后的观察

- 缺水家庭日由修订前的 `151` 降至 `130`；`no_labour_time_before_fetch` 由 `19`
  降至 `6`。原因是紧急取水允许照护与往返合并计时，避免同一照护时间被重复扣除。
  仍有 `98` 个家庭日受直接取水人数不足影响，另有 6 个家庭日无人能自行到水边。
- 固定劳动能力对照与动态身体结果并非单向改善或恶化，说明身体反馈改变的是行动轨迹，
  不能简单描述为只会放大短缺。
- 末日平均劳动能力由重复代谢影响修正前的约 `0.12` 变为约 `0.59`；这是修正重复
  扣减和恢复效果后的模型变化，不是以改善存活为目标的调参。
- 第 `6` 日起最低劳动能力低于预设审查下限，之后只能用于故障定位，不再用于生存结论。
- 个人活动记录共 `129961` 条；任务重叠、超能力和资格失败均为零；位置精度仍只到家庭营地。
- 遮蔽没有达到完整保护阈值的家庭为零，但 863 户、3602 人已有部分保护，
  建造进度跨日保留。
- 社会互助、教学和同住明确标记为尚未接入统一调度，不能由零事件推断合作意愿。
- 正式长期模拟：未启动。
