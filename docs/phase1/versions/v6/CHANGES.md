# v6 变更记录

## 范围

v6 保留 v1–v5 的失败结果和基线，只增加空间发现审计与完整信息诊断对照。

## 实现

- 每次迁移记录日期、家庭、原营地、新营地、距离、耗时、触发原因、
  迁移前后鱼类候选正存量格和存量。
- 每户每日记录直接观察新格、侦察新格、已知格、候选迁移格、
  是否考虑迁移、迁移未执行原因和当前鱼类候选状态。
- 新增 `candidate_limited` 与 `complete_resource_positions` 两种诊断模式。
- 两种模式共享世界、人口、技能、季节、身体、照护、走路时间、工具和加工规则。
- 完整信息只用于诊断，不是正式人物能力，也没有写入基线人物。

## 有限信息组

- 迁移 951 次，全部在第 1 日，平均距离 0.182 km。
- 第 5 日 940 户因迁移冷却未执行迁移。
- 第 2 日后日均新发现格为零。
- 第 7 日鱼类候选正存量格均值 0.049。
- 第 2 日 651 户捕鱼；后来退出的 238 户在第 4–5 日没有选择鱼。
- 退出队列食物比例 0.485275 → 0.158111 → 0.081406。

## 完整信息组

- 迁移 998 次，全部在第 1 日，平均距离 1.793 km。
- 第 7 日食物比例 0.4222，仍低于 80%。
- 第 7 日有 578 次鱼格选择、50 个不同鱼格。
- 原有限信息退出队列中，第 4 日 192 户、 第 5 日 203 户重新选择鱼。
- 原队列第 4–5 日全部 476 个家庭日都有正鱼群候选存量。

## 结论

候选与发现规则造成的假性受困已经成立；完整信息后仍有实际获取不足。
下一版必须先修正规则，不通过扩大探索半径或调高资源来追求通过。
