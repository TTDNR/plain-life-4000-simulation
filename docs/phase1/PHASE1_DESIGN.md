# Phase 1 设计与门禁

## 目的

Phase 1 不是长期模拟，也不评价 4000 人最终能否繁荣。它只回答三个问题：

1. 世界在人物投放前是否已有完整、来源清楚且确定的初始状态。
2. 在人物实际能力、信息和劳动时间下，是否存在可按时间窗检查的生存路径。
3. 人口、家庭、经历、技能、照护和生态承载之间是否一致。

当前 v2 结构化输入位于：

- `data/phase1/versions/v2/world.json`
- `data/phase1/versions/v2/survival.json`
- `data/phase1/versions/v2/population.json`
- `data/phase1/versions/v2/environment_baseline.json`

审计器位于 `tools/phase1_audit.py`，端到端生成和核验入口位于 `tools/run_phase1.py`，
模型实现位于 `plain_life/`。

## 事实状态

每个必需事实只能使用以下状态：

- `known`：已确定，必须附至少一个 `evidence` 标识。
- `assumption`：工程假设，必须有 `rationale` 和 `accepted`。未接受的假设会产生警告。
- `unresolved`：尚未确定，作为必需事实时直接阻断。

未知值不能用 `null`、任意默认值或运行时生成来绕过。

## 世界初始化

版本化的 `world.json` 固定以下顺序：

1. 先物化 50 平方公里的地形、水、生态、物质和土地状态。
2. 生成可复算的状态指纹和生成种子。
3. 再创建并投放人物。
4. 人物需求不得触发资源补充，也不得改变投放前的状态来源。

资源“存在”、人物“发现”、人物“知道如何使用”是不同状态。环境文件只记录前者的实际
分布；后续模拟必须分别维护发现知识、辨认结果和加工技能，不得从地图资源直接生成全知行为。

## 封闭边界

边界允许：

- 日照和天气作为明确的时空输入。
- 降雨作为明确的环境输入。
- 蒸发和可选的排水作为明确的环境输出。

边界不允许：

- 外来鱼群、泥沙、种子、生物或其他物资输入。
- 通过排水口反向获得物质或信息。
- 不同人尝试穿越同一地点时看到不同空间规则。
- 边界移动、伤害探索者或主动提供提示。

降雨是输入不等于淡水无限。地表水和地下水仍受地形、储水、蒸发、污染和抽用影响。

## 生存核验

审计器要求以下六条依赖链都有具体解：

- `water`
- `food`
- `shelter`
- `fire`
- `tools`
- `stable_supply`

每条依赖链必须覆盖“找到、到达、辨认、加工、劳动、失败风险、维护或再生”。仅有技能记录
不能作为成功证据。技能只说明过去学习和练习，当前材料、体力、工具与试错仍会决定结果。

四个固定时间窗为：

- `initial_days`
- `initial_weeks`
- `first_season_transition`
- `first_year_plus`

每个时间窗必须有瓶颈、可行路径、最可能失败点、容量余量和依据。总地图生物量不能代替
可用食物计算。食物还需要检查成熟、可到达、可识别加工、时间体力成本、运输分配、保存、
家庭能力差异和对未来繁殖的影响。

## 人口与聚落

`population.json` 的门禁要求：

- 总数严格为 4000。
- 人口快照中年龄阶段、亲属、孕育、婴儿和照护引用一致。
- 技能有学习来源和非负实践次数。
- 家庭可以依赖、冲突和不平等，不能被强制完全合作。
- 家庭之间没有既存私人交情，但共同语言、习俗和原乡经历可以形成信任入口。
- 旧财产和职位不转为新世界资产或权力。
- 不人为补齐关键工匠，也不保证技能后继有人。
- 所有人只在一个初始投放点进入世界，不预分配群体或政权。
- 探索知识不自动全局共享；另建住所不等于立即形成独立政权。

## 门禁结果

- `PASS`：没有阻断项和未接受假设，可以进入长期模拟。
- `CONDITIONAL`：没有阻断项，但仍有未接受的工程假设。
- `BLOCKED`：至少一个必需事实未解决或一致性检查失败。

长期模拟启动命令不得使用 `--allow-failed`。该参数只用于保存未通过的报告。

## 专项核验范围

`tools/run_phase1.py` 会：

1. 从固定种子生成环境并计算初始状态指纹。
2. 按家庭角色模板生成 4000 人和亲属、照护、孕育与经历记录。
3. 复制世界状态，在副本上运行短期或最多 365 天的专项核验。
4. 按家庭分配照护后的劳动时间。
5. 模拟饮水、食物获取、遮蔽、火、工具、探索和迁移。
6. 消耗副本中的资源并按物种规则再生。
7. 生成环境资源清单、生存核验和初始化一致性报告。

专项结果不写入正式世界历史，不触发跨代模拟，也不定义心理、经济、文化和战争规则。

## 当前专项结果

- v2 是暖湿早季第 90 日基线，投放瞬间只有 1 个营地。
- 最初数日、最初数周、季节转换和完整年度全部失败。
- 无成本重新分配后仍有 340 天不足，不能把失败归因为缺少合作。
- 饮水存在实际取水路径，但食物、遮蔽、火和稳定供给未通过。
- 资源账目闭合且库存非负，但自然损失尚未实现。
- 年度结果只是固定人口需求压力测试，没有身体、劳动和死亡反馈。
- 家庭内部差异分配和家庭间交换规则尚未定义，门禁保持 `BLOCKED`。

v1 温带秋季基线和结果保存在 `data/phase1/versions/v1/` 与
`docs/phase1/versions/v1/`，没有被 v2 覆盖。
